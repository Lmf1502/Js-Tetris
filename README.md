Tetris Project
Sparkle Blocks is a browser-based puzzle game I developed using JavaScript. Inspired by classic falling-block games, this project challenged me to implement piece movement, rotation mechanics, collision detection, line clearing, and sprite-based visual effects.

To make the gameplay more engaging, I created animated sparkle effects using sprites that trigger during gameplay events, adding visual feedback and polish to the experience.

How to Run
Download or clone the project files.
Open the index.html file in your web browser.
The game will launch automatically.
Controls
Left Arrow: Move piece left
Right Arrow: Move piece right
Up Arrow: Rotate piece
Down Arrow: Drop piece faster
Technologies Used
JavaScript
HTML5 Canvas
Sprite Animation
